# 💬 Real-Time Chat Application

A modern **real-time chat application** built using **Spring Boot WebSockets (STOMP + SockJS)** on the backend and **pure HTML, CSS, and JavaScript** on the frontend.  
The application enables multiple users to communicate instantly without page refresh.

---

## 🚀 Features

- Real-time messaging using WebSockets  
- STOMP protocol with SockJS fallback for reliable connections  
- Modern and clean Glassmorphism-style user interface  
- Chat bubbles for sender and receiver messages  
- Supports multiple concurrent users  
- Responsive and mobile-friendly design  
- Built using plain HTML, CSS, and JavaScript  
- Messages update instantly without reloading the page  

---

## 🛠 Tech Stack

### Backend
- Java  
- Spring Boot  
- Spring WebSocket  
- STOMP Protocol  
- SockJS  

### Frontend
- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  

## RUN
http://localhost:8080/chat
